# 🤖 CodeAlpha AI & ML FAQ Chatbot

An NLP-based FAQ chatbot developed as part of the CodeAlpha Artificial Intelligence Internship.

## 🚀 Live Demo

Try the chatbot online: https://huggingface.co/spaces/Thakur-sejal18/CodeAlpha_FAQChatbot

## 📌 Project Overview

This chatbot answers frequently asked questions related to Artificial Intelligence, Machine Learning, Deep Learning, Natural Language Processing, Computer Vision, and Chatbots.

The system uses Natural Language Processing, TF-IDF vectorization, and Cosine Similarity to find the most relevant FAQ and return its answer.

## 🎯 CodeAlpha Task

**Task 2 – Chatbot for FAQs**

### Requirements Implemented

- FAQ collection
- NLP text preprocessing
- TF-IDF vectorization
- Cosine similarity
- Similarity-based FAQ matching
- Confidence/relevance handling
- Interactive Gradio interface

## 🧠 How It Works

1. User enters a question.
2. The question is preprocessed.
3. The text is converted into a TF-IDF vector.
4. Cosine similarity is calculated against the stored FAQ questions.
5. The most similar FAQ is selected.
6. A relevance check prevents unrelated responses.
7. The corresponding answer is displayed.
